# AI 数据智能平台业务与技术全景图 Implementation Plan

**Goal:** 重构 `/architecture`，以“技术分层 → 平台能力 → 业务应用”为主线展示当前真实架构，支持节点详情、三条端到端链路联动和 SVG/PNG 面试图导出。

**Constraints:** 只展示当前已实现能力；不新增后端 API、数据库迁移或第三方前端依赖；保留 `/architecture` 和现有 `ErDiagram`；中文业务文案、英文技术名。

## Task 1: 类型化架构数据源

- 先写失败测试，覆盖节点唯一性、边引用、工作流引用、应用路由和禁止规划能力。
- 新增架构层、节点、边、工作流、技术详情类型和当前真实配置。
- 运行前端单元测试并提交。

## Task 2: 可交互技术—业务全景图

- 先写失败测试，覆盖节点选择、工作流高亮和应用链接派生逻辑。
- 实现桌面横向、移动纵向的主图、节点详情和三条链路切换。
- 使用语义化按钮、键盘焦点、文字/线型双重编码和文本替代。
- 运行前端检查并提交。

## Task 3: 面试图 SVG/PNG 导出

- 先写失败测试，覆盖 SVG 尺寸、标题、关键层级和三条链路。
- 从同一架构数据生成 16:9 SVG；浏览器端支持下载 SVG 和 1920×1080 PNG。
- 文件名固定为 `ai-data-platform-architecture-current.svg/png`。
- 运行前端检查并提交。

## Task 4: 重构架构页并完成视觉验收

- 将交互全景图、详情、链路、完整技术作用映射、ER 图和项目边界组装进现有页面。
- 删除页面中过时的“三个功能页”和旧 RAG/Agent 表述。
- 运行 lint、TypeScript、单元测试和 production build。
- 浏览器验证 1440px、390px、键盘交互和图片导出。
- 完成整分支代码审查与必要修复。
